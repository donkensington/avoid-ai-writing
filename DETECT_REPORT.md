# Detect Report (AI-writing patterns)

## 1) Issues found

### P0 — Credibility killers (fix immediately)
- **Vague attribution:** “**experts believe** Acme is poised to disrupt the market.”
- **Vague attribution:** “**Studies show** that companies utilizing comprehensive monitoring solutions can ascertain issues 40% faster.”
- **Significance inflation:** “a **rigorous statistical analysis** ... identify which factors are significant drivers...” (inflated framing repeated throughout).

### P1 — Obvious AI smell (fix before publishing)
- **Major duplication artifact:** The full report content appears **twice**, starting again at “**1. Introduction**” mid-document.
- **Template/formulaic framing:** “The insights generated are directly actionable...”, “By modelling the relationship..., the organisation can move from intuitive decision-making to evidence-based planning...”
- **Word-list / inflated diction cluster:** “**rigorous**,” “**optimise** resource allocation,” “**substantial**,” “**exceptional predictive performance**,” “**fundamental importance**,” “**compelling 11.5x return**,” “**structurally challenging environment**.”
- **Copula-avoidance pattern:** “**captures** investment...,” “**reflecting** meaningful differences...,” “**supporting** evidence-based decisions...”, “**yields** several actionable recommendations...” where simpler “is/has” phrasing would often be clearer.
- **Transition boilerplate:** “**Notably**...”, “**Given** the small sample size...”, “**In summary**...”
- **Mechanical recommendation cadence:** Repeated imperative bullets (“Prioritise... Invest... Size... Monitor... Treat...”) with uniform structure.

### P2 — Stylistic polish (fix when time allows)
- **Uniform academic rhythm:** Many sentences use similar length and clause structure, producing a polished but machine-like cadence.
- **Hedging / calibration fillers:** “**does not meaningfully compromise inference**,” “**should be interpreted cautiously**,” “**acceptable bounds**.”
- **Generic conclusion pattern:** “**In summary, this model provides a reliable, statistically validated tool...**” (broad closing instead of a sharp, specific decision statement).
- **Minor list inflation:** Several sections overuse numbered and bullet structures where concise prose would read more naturally.

## 2) Assessment

### Definitely fix
1. Remove the duplicated second copy of the report.
2. Replace vague attributions (“experts believe,” “studies show”) with named sources or remove.
3. Tone down significance inflation and sales-like claims (“exceptional,” “compelling”) unless supported with explicit benchmark comparisons.
4. Simplify formulaic transitions and repetitive executive-style cadence.

### Judgment calls (may be acceptable depending on audience)
1. The formal, highly structured tone is normal for business-school style reports.
2. Some hedging language is acceptable in statistical reporting.
3. Bullet-heavy recommendation sections can be useful for executive readers, even if they raise AI-style signals.

### Overall verdict
- **High AI-likelihood surface style**, mainly due to duplicated full text, repeated template phrasing, vague attribution, and consistently polished uniform rhythm.
- **Substantive statistical content may still be valid**, but the writing style should be edited before submission/publication.
